# 필요한 외부 스킬과 도구

## 필수 도구 설치와 우선 사용

Aside와 agent-desktop은 공통 필수 구성요소다. Contentrium Works 설치·업데이트 시 두 도구의 스킬과 실행 프로그램·연결 도구를 각각 확인하고, 없는 구성요소는 검증된 공식 출처에서 설치·검증한다. 해당 통상 설치는 상시 승인 범위이므로 설치 여부를 다시 묻지 않는다. 사용자가 설치 제외나 다른 도구를 명시하면 그 지시를 우선한다. 단순 질의마다 설치를 실행하지 않으며, 일반 작업에서는 필요한 지정 도구가 없을 때 설치하고 원래 작업을 이어간다.

웹 검색·웹페이지 탐색에는 Aside를 우선 사용한다. 데스크톱 앱 UI 직접 조작에는 agent-desktop의 헤드리스 방식을 우선 사용한다. 사용 전 해당 스킬의 현재 지침과 플랫폼 지원 기능을 읽는다. 명령어·설치 출처·프로필·연결 방식은 현재 문서에서 확인하고 추측하지 않는다. 전용 플러그인·API·CLI·파일 조작에 불필요하게 브라우저나 데스크톱 조작을 강제하지 않는다.

스킬 파일의 존재와 실행 프로그램의 설치·작동은 별도로 확인한다. 버전과 인식 상태, 해당 작업에 필요한 연결·기능을 검증한다. 실행 파일이 있어도 로그인·연결이 막혔다면 사용 준비 완료로 보고하지 않는다. 설치 실패 시 원인과 필요한 조치를 알리고 단순히 설치 지침이 없다는 이유로 끝내거나 다른 UI 도구로 임의 대체하지 않는다.

각 OS·CPU·실행 호스트에 맞는 공식 배포판과 지원 기능을 확인한다. Windows용 바이너리·명령을 Mac에 적용하거나 지원되지 않는 기능을 우회하지 않는다. 공식 출처·플랫폼 지원을 확인할 수 없으면 설치를 보류하고 실제 제약을 알린다. 개인 실행 경로·계정·인증정보·수신자는 각 환경에서 관리하며 다른 직원의 설정을 복제하지 않는다.

## 기타 의존 도구

문서·표·영상 등 실제 제작은 해당 전문 스킬과 도구를 사용한다. 위 두 도구 외 구성요소는 현재 작업에 필요한 것만 확인하고 아래 승인 절차를 적용한다. 모든 외부 도구를 일괄 설치하지 않는다.

## 포커스 보호

사용자의 실제 마우스·키보드·전경 창을 방해하지 않는 방식으로 수행한다. 포커스 보존이 확인된 전용 API·파일 조작·비활성 조회를 우선한다. 헤드리스·백그라운드 플래그나 접근성 API 사용만으로 포커스 보존을 보장하지 않는다.

UI 변경 직전에 현재 전경 창과 대상 창을 확인하고 입력 간섭, 앱 활성화, 메뉴·대화상자 생성 가능성을 판단한다. 브라우저의 탭 선택·창 표시도 같은 기준으로 판단한다. 전경 창 확인만으로 다음 동작의 안전을 추정하지 않는다. 필요한 상태를 확인할 수 없으면 안전하다고 간주하지 않는다.

백그라운드 버튼 실행·메뉴 열기·창 실행 또는 복원·대화상자 호출 등 포커스를 보장할 수 없는 동작은 보내기 전에 건너뛴다. 확인된 비활성 API·파일 경로나 이미 허용된 격리 환경을 사용한다. 안전한 경로가 없으면 해당 동작을 멈추고 이유를 알린다. 실제 입력·포커스 전환이 필요하면 해당 범위의 명시적 허락을 기다린다. 도구 지정·설치, 이전 명령 실패나 재시도 가능 응답을 그 허락으로 확대하지 않는다. 실패 후 사용자 입력을 사용하는 방식으로 자동 전환하거나, 포커스를 빼앗은 뒤 원래 창을 강제 활성화하지 않는다.

검증할 때 도구의 성공 응답과 실제 동작, 사용자 마우스 좌표와 전경 창 변화는 구분한다. 사용자가 움직이는 마우스의 좌표 변화 원인을 단정하지 않는다. 별도 커서 등 시각 표시를 사용하는 경우 표시 응답과 실제 이동도 구분하되 공용 스킬에서 특정 표시 기능을 필수로 요구하지 않는다. 필요한 포커스 대조 시험은 활성화 없이 표시하는 별도 테스트 창에서 위험한 실행을 사전 생략하고 관찰한다. 이미 확인된 포커스 탈취를 실사용 창에서 반복하지 않는다. 세션을 사용하는 도구는 해당 절차에 따라 오류 시에도 종료한다.

Windows와 macOS의 전경 창 조회 방식·자동화 권한·앱 활성화 동작은 사용하는 도구에서 각각 확인한다. 다른 OS에서 성공한 결과를 현재 환경의 안전 근거로 대신하지 않는다. 조회 권한이나 상태 확인 수단이 없으면 포커스 보존을 미검증으로 표시하고 위험한 조작을 보류한다. OS 보안 권한을 임의 변경하거나 우회하지 않는다.

## 설치 승인과 검증

Aside·agent-desktop의 통상 설치는 위 상시 승인으로 진행하며 설치 대상·출처·범위를 알린다. 그 외 도구 설치는 구성요소, 검증된 배포 출처, 설치 위치/범위, 필요한 권한·로그인·비용을 설명하고 기존 승인이 없으면 명시적 승인을 기다린다. 같은 설치를 이미 승인받았으면 재질문하지 않는다. 답변 없음은 승인이 아니다. 공식 출처를 확인할 수 없으면 미확인 명령으로 설치하지 않는다. 사용 가능한 설치 전용 스킬과 플랫폼 지침을 따른다. 특정 직원 경로나 변경될 수 있는 설치 URL을 공용 기본값으로 하드코딩하지 않는다.

설치 후 버전·인식 여부·해당 작업에 필요한 기능을 검증하고 원래 작업을 재개한다. 로드되지 않으면 새 세션/재시작 필요 여부를 확인한다. 설치·업데이트 실패와 인증·환경 제약을 구분해 알린다. 스킬 설치를 계정 변경·결제·보안 해제·불필요한 권한 확대의 승인으로 해석하지 않는다. 직원별 인증정보를 공용 패키지에 포함하지 않는다.
