# 필요한 외부 스킬과 도구

현재 요청에 필요한 기능을 먼저 정한다. 사용 가능한 스킬·연결 도구·실행 파일을 확인한다. 단순 답변을 위해 설치하거나 가능한 모든 스킬을 일괄 설치하지 않는다. 기존 문서·표·영상·기획 등 전문 스킬을 활용하고 본 스킬이 그 제작 절차를 대체하지 않는다.

설치가 필요하면 구성요소, 검증된 배포 출처, 설치 위치/범위, 필요한 권한·로그인·비용을 설명하고 명시적 승인을 기다린다. 같은 설치를 이미 승인받았으면 재질문하지 않는다. 공식 출처를 확인할 수 없으면 임의 검색 결과나 미확인 명령으로 설치하지 않는다. 사용 가능한 설치 전용 스킬과 플랫폼 지침을 따른다.

스킬 파일과 실제 CLI·앱·런타임을 별도로 확인한다. 설치 후 버전·인식 여부·해당 작업에 필요한 기능을 검증하고 원래 작업을 재개한다. 로드되지 않으면 새 세션/재시작 필요 여부를 확인한다. 설치·업데이트 실패와 인증·환경 제약을 구분해 알린다. 스킬 설치를 계정 변경·결제·보안 해제·불필요한 권한 확대의 승인으로 해석하지 않는다.

예: agent-desktop이 필요한 환경에서 스킬만 있으면 CLI도 확인한다. 둘 다 설치돼도 헤드리스 지원을 확인한다. 설치 승인은 실제 마우스·키보드·포커스 사용 승인이 아니다. 사용자의 헤드리스 정책을 유지하고 불가능하면 제한을 알린다. 다른 도구로 우회하지 않는다.

특정 스킬 이름이나 설치 URL을 모든 직원 환경에 강제하지 않는다. 현재 적용되는 도구 선택 지침과 확인된 카탈로그를 따른다. 직원별 인증정보를 공용 패키지에 포함하지 않는다.
