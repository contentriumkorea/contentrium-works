# 설치와 상시 검토 설정

이 문서는 사용자가 Contentrium Works의 설치·업데이트를 요청했을 때만 적용한다. 일반 작업 중 스킬이 호출됐다는 이유로 개인 지침을 변경하지 않는다. 이 설치 안내에 따른 설치 요청은 스킬 배치와 아래 상시 검토 문단 추가를 함께 수행하는 흐름이다. 사용자가 지침 변경을 제외했으면 그 제한을 따른다. 적용 전 기존 지침은 유지하고 해당 문단만 추가한다고 짧게 알린다.

## 설치 담당 에이전트 절차

1. 현재 사용자의 실제 Codex 홈과 스킬 설치 위치를 확인한다. 기본 경로를 추측해 다른 프로필에 설치하지 않는다. 기존 설치가 있으면 로컬 수정·버전을 확인하고 실행용 파일을 교체하기 전에 프로젝트 내부 승인된 위치에 백업한다. 직원 개인 설정을 배포 패키지에 넣지 않는다.
2. 스킬의 SKILL.md, agents, references, assets를 설치한다. 기존 설치본의 무관한 파일을 삭제하지 않는다. 설치본을 다시 읽고 원본과 비교한다.
3. 전역 AGENTS.override.md의 유효한 내용이 있으면 그 파일, 아니면 AGENTS.md 등 현재 환경에서 실제 적용되는 전역 개인 지침을 확인한다. 프로젝트별 AGENTS.md에만 추가해서 전역 적용했다고 보고하지 않는다. 앱 설정이 별도 개인 지침을 관리한다면 지원 도구로 실제 적용 위치를 확인한다. 확정할 수 없으면 파일을 임의 생성하지 말고 제한을 알린다.
4. 해당 파일을 읽고 아래 문구 또는 같은 의미의 Contentrium Works 상시 검토 규칙이 이미 있으면 추가하지 않는다. 관련 규칙이 충돌하면 기존 규칙을 지우거나 우선순위를 임의 변경하지 말고 구체적으로 확인한다.
5. 기존 파일을 승인된 프로젝트 내부 비공개 백업 위치에 보존한다. 그 백업을 ZIP·공유 폴더·공개 저장소에 자동 포함하지 않는다. 수정 직전에 원본이 바뀌지 않았는지 확인한다. 기존 내용과 인코딩·줄바꿈을 유지하면서 아래 문단만 구분하여 한 번 추가한다. 파일이 없다면 적용 위치를 확인한 후 이 문단만 새로 만든다. 사용자 전체 개인 지침을 제공된 예시로 교체하지 않는다.
6. 저장한 파일을 다시 읽어 기존 내용이 보존됐고 상시 검토 문단이 중복되지 않았는지 확인한다. 추가 문단 외 변경이 있으면 완료로 보고하지 말고 원인을 확인한다. 스킬 설치 위치, 변경한 지침 파일, 추가 범위와 백업 위치를 보고한다. 개인 지침 본문·인증정보를 채팅에 덤프하지 않는다.
7. 새 세션에서 설치 스킬과 적용 지침의 인식을 확인한다. 현재 세션에서 확인할 수 없으면 새 대화/재시작 후 확인이 필요하다고 명시한다. 파일 설치 완료와 런타임 인식 확인을 구분한다.

## 추가할 공통 문단

## Contentrium Works 상시 검토

모든 요청을 시작할 때 설치된 `contentrium-works` 스킬에 따라 작업 관리 적용 필요성을 검토한다. 별도 호출을 기다리지 않는다. 프로젝트 시작·진행·저장·납품·기록·인계·보관·재개에는 관련 절차를 적용하고, 단순 질의에는 불필요한 파일·폴더·설치를 만들지 않는다. 새 분류·정리와 외부 자료 반입은 기존 승인 또는 명시적 위임 범위가 없으면 구체적 안을 제시하고 승인받는다. 스킬이 없거나 읽을 수 없으면 필요한 작업에 앞서 이를 알리고 설치 여부를 확인한다. 기존 프로젝트 구조와 연결을 유지한다.

## 제한

자동 선택 허용은 매 요청 실행을 강제하는 후크가 아니다. 상시 검토 문단까지 설정해도 모델의 모든 행동을 기술적으로 강제하는 보안 기능은 아니다. ZIP을 수동으로 복사만 하면 개인 지침이 자동으로 변경되지 않는다. 이 문서의 설치 절차를 수행하는 에이전트가 함께 설정해야 한다. 별도 자동 설치 실행 파일은 제공하지 않는다.
