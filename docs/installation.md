# Contentrium Works 직원 설치 안내

버전 1.0.10. 직원은 이 ZIP을 Codex에 제공하고 다음과 같이 요청하면 된다.

> 첨부한 Contentrium Works를 설치해줘. Aside와 agent-desktop 스킬·실행 도구도 확인해서 없으면 설치·검증하고, 포함된 설치 안내에 따라 기존 개인 지침은 그대로 유지하고 상시 검토 문구만 중복 없이 추가해줘.

직원이 개인 지침을 직접 편집하거나 별도 개인 지침 파일을 전달받을 필요는 없다. 설치 담당 에이전트가 스킬 설치와 공통 문구 추가를 함께 수행한다. 개인 계정·Telegram 설정은 이 패키지에 포함하지 않는다.

## 설치 담당 에이전트에게

먼저 contentrium-works/references/installation.md를 읽고 따른다. 스킬의 설치/업데이트 요청 범위에서 기존 설치를 확인하고 스킬 파일을 설치한다. 실제 적용되는 전역 개인 지침을 읽어 기존 내용·보안·도구 설정을 모두 유지한 채 공통 상시 검토 문단만 한 번 추가한다. AGENTS.override.md의 적용 여부를 확인한다. 같은 의미의 규칙이 있으면 중복 추가하지 않는다. 충돌하는 기존 규칙이 있으면 임의 수정하지 않고 질문한다.

변경 전 원본을 승인된 비공개 작업 위치에 백업하고 수정 직전에 변경 여부를 확인한다. 설치 후 기존 본문 보존·추가 범위·중복 여부·스킬 파일을 검증하고 결과를 보고한다. 다른 직원의 지침을 통째로 복사하거나 이 ZIP으로 개인 지침 전체를 교체하지 않는다. 프로젝트별 지침만 바꿔 전역 설정 완료로 보고하지 않는다.

## 설치 후

새 대화에서 스킬과 상시 검토 지침이 인식되는지 확인한다. 평소에는 스킬 이름을 호출하지 않고 작업을 요청한다. 단순 질문에는 파일을 만들지 않고, 새 분류·외부 자료 복사는 해당 승인 기준을 따릅니다. Aside·agent-desktop의 통상 설치는 별도 재승인 없이 진행하고 다른 도구는 해당 승인 기준을 따릅니다.

ZIP을 수동 복사만 하면 상시 검토 문구가 자동 추가되지는 않는다. 위 설치 요청과 절차로 함께 설정하는 방식이며 별도 설치 실행 파일은 없다. 자동 호출 설정은 기술적 강제 실행이나 Dropbox 동시 작업 충돌 방지 보장이 아니다.

## 배포 범위

공용 스킬과 설치 안내·공통 문구만 포함한다. 개인 기본 지침 적용안·작업 기록·테스트·비공개 백업은 제외한다. Aside·agent-desktop은 설치·업데이트 과정에서 확인하고 없는 구성요소를 별도 재승인 없이 설치·검증한다. 그 외 외부 도구는 기존 승인 범위를 확인한다. 공개 게시·직원 전송·자동 업데이트 서비스는 이 패키지를 만드는 작업에 포함하지 않는다.

## 공용 도구 정책
Aside를 웹 작업에, agent-desktop 헤드리스를 데스크톱 UI 직접 조작에 우선 사용합니다. 두 도구는 공통 필수 구성요소이며 누락 시 별도 재승인 없이 공식 출처에서 설치·검증합니다. 전용 API·파일 조작과 사용자 지정 예외는 유지합니다. 포커스 보호 규칙을 따르며 개인 경로·계정 설정은 배포하지 않습니다.

## Windows·macOS 공통 사용과 검증 범위

같은 ZIP을 사용하며 각 PC의 실제 Codex 스킬 설치 위치에 설치합니다. 다른 직원의 절대경로·개인 설정은 복사하지 않습니다. 설치 후 각 OS의 새 대화에서 스킬과 상시 검토 지침 인식을 확인하세요. 다른 AI 도구의 자동 설치·호출 지원은 별도 확인이 필요합니다.

v1.0.10는 문서·패키지 정적 검사와 Windows 압축 해제·파일 비교를 검증했습니다. **Mac 실기기 설치·새 대화 인식·파일 작업·포커스 보호 및 Windows↔Mac Dropbox 왕복은 미검증입니다.** 실제 제작 앱의 폰트·플러그인·연결 자산도 받는 PC에서 확인해야 합니다.
